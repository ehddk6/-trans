# 로컬 다중 ASR 교차검증 방법론 v1

## 목적

ChatGPT가 원음을 직접 청취할 수 없는 환경에서도 일본어 성인영상 자막의 고위험 구간을 단일 ASR에 의존하지 않고 검증한다.

이 절차는 번역을 ASR에 맡기지 않는다. 로컬 PC는 음성 증거와 일본어 후보를 만들고, 최종 의미 판정·한국어 재구성·전체 QA는 프로젝트의 번역 원칙과 Subtitle Forensics 결과에 따라 수행한다.

## 역할 분리

### 사용자 PC

- 원본 음성에서 고위험 장면 추출
- 원본 음원과 대사 강조 음원 생성
- 원본·대사 강조 무편향 ASR 실행
- 충돌 장면에 한해 no-VAD·prompted 패스 실행
- 중간 결과 체크포인트 저장
- 작품별 `work_audio.zip` 생성

### ChatGPT

- 구조 기준본 잠금
- ASR 후보와 기존 일본어 자막 정렬
- 질문·부정·명령·허용·거절·화자·대상·위치 검토
- 사진·화면·앞뒤 문맥과 교차검토
- 원문 충실본과 감상용 자연본 작성
- evidence-ledger·uncertainty-map·회귀 검사·QA 보고서 생성

사용자는 일본어 후보를 선택하거나 일본어 문장을 직접 수정하지 않는다.

## 위험 기반 처리

전체 음성을 여러 번 전사하지 않는다. Subtitle Forensics가 지정한 P1·P2 블록과 다음 요소를 우선 처리한다.

- 부정·금지·허용
- 질문과 진술
- 화자 전환
- 행동의 주체와 대상
- 안과 밖, 앞과 뒤
- 신체 부위와 위치
- 사정 전후
- `行く`의 이동·절정 구분
- `出す`의 일반 동작·사정 구분
- `入れる`의 일반 동작·삽입 구분
- 신음·호흡·무발화와 실제 단어의 구분
- 일본어와 기존 한국어의 큰 불일치
- 화면과 자막의 충돌

인접 블록은 음성 분석을 위해 장면으로 합칠 수 있지만 최종 SRT의 블록 수·번호·타임코드·순서는 바꾸지 않는다.

## 적응형 ASR 패스

모든 장면에 먼저 두 패스를 실행한다.

1. `original_unbiased`: 원본 음원, VAD 사용, 프롬프트 없음
2. `dialogue_unbiased`: 보수적으로 대사를 강조한 음원, VAD 사용, 프롬프트 없음

다음 조건에서만 추가 패스를 실행한다.

- 두 결과의 문자 유사도가 기준 이하
- 한쪽 결과가 비어 있음
- 평균 로그확률이 낮음
- 무발화 확률이 높음
- 처리 오류가 발생함

추가 패스:

3. `original_no_vad`: 원본 음원, VAD 해제
4. `original_prompted`: 원본 음원, 일본어 전사 원칙과 기존 문맥을 프롬프트로 제공

prompted 결과는 문구 유도 가능성이 있으므로 무편향 결과보다 낮은 증거로 취급한다.

## 증거 독립성

같은 Whisper 모델에서 입력 처리나 설정만 바꾼 결과는 완전히 독립된 증거가 아니다.

다음 결과를 별개의 다수 증거로 계산하지 않는다.

- 원본·대사 강조 음원을 같은 모델로 인식한 결과
- VAD 설정만 바꾼 결과
- prompt만 추가한 결과
- beam·temperature 등 추론 설정만 바꾼 결과

이 결과들은 오인식 위치와 가능한 일본어 후보를 찾는 보조 자료다. 단순 다수결로 의미를 확정하지 않는다.

## 장면 판정 등급

- `stable`: 원본과 대사 강조 ASR의 핵심 의미가 안정적으로 일치
- `normalized`: 조사·반복·문장 경계만 다르고 의미는 일치
- `context-resolved`: ASR은 갈리지만 앞뒤 대화와 장면 문맥으로 하나의 의미만 성립
- `nonverbal`: 신음·호흡·웃음·무발화로 판단
- `unresolved`: 부정·화자·행동·대상·위치·성적 의미가 끝까지 갈림

`unresolved`는 자연스러운 창작으로 메우지 않는다. 확정된 의미 범위만 번역하고 남은 불확실성은 uncertainty-map에 기록한다.

## 검증 상태

- `text-crosschecked`: 일본어 자막·한국어 후보·사진·문맥 검토
- `audio-asr-crosschecked`: 로컬 다중 ASR 교차검토, 직접 청취 아님
- `audio-human-verified`: 일본어 청취 가능자가 원음을 직접 확인
- `final`: 필요한 증거 검토와 전체 구조·의미·한국어·회귀 검사 완료

다중 ASR만 사용한 결과를 `audio-human-verified`라고 표시하지 않는다.

## 보고 원칙

- 원음을 직접 듣지 않았으면 직접 청취했다고 쓰지 않는다.
- 같은 모델의 여러 패스를 독립적인 다수 증거라고 쓰지 않는다.
- P1·P2만 처리하고 작품 전체가 검수됐다고 보고하지 않는다.
- 구조 검사는 최종 SRT 전체를 실제 코드로 수행한다.
- 미확정 구간과 수행하지 못한 검증은 QA 보고서에 기록한다.
