# 검증 기준

구조 검사는 블록 수, 번호 누락·중복·역전, 타임코드 형식·순서·변경, 빈 자막을 검사한다. 문자 검사는 일본어 잔존, `[불명]`, 작업용 태그, 번역자 주석, 괄호 해설, 깨진 문자와 비정상 공백을 검사한다.

가독성 검사는 3줄 이상, 42자 초과, 초당 문자 수 경고, 반쪽 문장 후보를 보고한다. 내용 회귀 검사는 연속 중복, 후보 문장 재사용, 질문·부정·허용·거절 표면 신호 변화와 고유명사·숫자 위험을 경고한다.

자동 검사는 오류 후보를 제시할 뿐 의미를 확정하거나 자막을 자동 수정하지 않는다. 실행하지 못한 검사는 `미검증`으로 남긴다. 오류가 있으면 실패, 경고만 있으면 경고, 오류가 없으면 통과로 집계한다.
