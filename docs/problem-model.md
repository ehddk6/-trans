# 번역 문제 모델 v2

각 블록은 장면 상태와 연결되지만, 아래 슬롯 중 근거가 없는 값은 추정하지 않는다. 슬롯 값은 `null`(발화에 해당 정보 없음), `unknown`(있을 수 있으나 확정 불가), `confirmed`, `contradicted`로 기록한다.

| 층 | 입력 | 출력 | 대표 오류 | 자동화 한계 |
| --- | --- | --- | --- | --- |
| 구조 | 기준 SRT | 번호·시간 잠금 | 병합/분할/경계 누수 | 구조만 검증 가능 |
| 시간 | 음성·정렬 | token 시간·경계 경고 | 부정/의문 종결어 위치 오배정 | 정렬 실패는 의미 실패가 아님 |
| 일본어 문자 | JA SRT·ASR | 후보 전사 | 동음이의·ASR 환각 | 직접 청취 없이 확정 불가 |

## 결정 규칙

1. 구조 기준본은 고정한다. 구조 문제는 번역 결과가 아니라 QA에 기록한다.
2. critical 슬롯(극성, 의문, 요청 강도, 허용/금지, 행위자, 대상, 위치, 완료, 성적 의미, 화자)에 확정값 충돌이 하나라도 있으면 escalation한다.
3. 고위험 블록에 상충하는 해석이 있으면 근거를 갖춘 후보를 둘 이상 원장에 기록한다. 근거 없는 가설 두 개를 만들지 않는다.
4. `source-faithful`과 `viewer-natural`은 같은 확정 프레임에서 독립 생성한다. 둘 중 하나가 원문에 없는 구체성을 추가하면 실패다.
5. 최종 SRT에는 프레임, 근거, 미해결 표식을 넣지 않는다. 그것들은 별도 산출물에만 남긴다.
