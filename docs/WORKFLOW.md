# 작품별 작업 절차

0. 공용 자료·버전·해시·실행 환경을 검사한다.
1. 구조 기준본, 일본어 기준본, 기존 한국어, 음성·영상, 사진, ASR 결과의 역할을 확정한다. 후보가 여러 개면 중단한다.
2. 구조 기준본의 블록 번호·타임코드·순서를 잠근다.
3. Subtitle Forensics를 실행하거나 기존 결과를 어댑터로 수집한다. 실행 불가 시 사유를 기록한 구조 기반 큐만 만든다.
4. P1/P2 장면을 준비하고 모든 장면에 `original_unbiased`, `dialogue_unbiased`를 먼저 실행한다. 충돌·저신뢰 때만 추가 패스를 실행한다.
5. 사람 검수자가 확정한 말투·호칭·고유명사·전문 용어는 consistency ledger에 기록하고, 구조·근거·충돌을 검증한다. 미확정·충돌 항목은 자동 치환하지 않는다.
6. 장면 단위로 화자·상대·화행·부정·행동·대상·위치·시제·성적 의미·근거·확신도를 판정한다. translation queue는 현재 블록과 관련 있는 confirmed consistency 항목만 선택해 포함한다.
7. 결정 템플릿 또는 부분 검수 결정에서 `build-uncertainty-review-queue`를 만들고, 미확정 상태·근거 참조·일관성 충돌·기존 P1/P2 위험·자동 QA 경고를 이유별로 정렬해 사람 검수 순서를 정한다. 이 큐는 의미를 자동 확정하지 않는다.
8. 원문 충실본을 먼저 만들고 감상용 자연본을 별도로 만든다. `apply-translations --strict`는 결정의 evidence reference와 기록된 consistency conflict가 원본 translation queue와 일치하는지 대조한다. 두 자막은 구조를 공유한다.
9. 전체 블록을 다시 검수하고 evidence ledger·uncertainty map·change log를 갱신한다.
10. 구조·문자·가독성·중복·회귀 검사를 실제 코드로 실행한다.
11. 검증 상태를 증거 수준에 맞게 기록하고, 미검증·미확정 구간은 QA에 남긴다.
12. 새 버전으로만 패키징한다. 기존 산출물은 덮어쓰지 않는다.

`run` 명령은 의미 판정이나 번역이 완료되지 않은 상태에서 완성본을 만들지 않는다.
