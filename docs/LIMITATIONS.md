- 위험 모델은 자동 오역 확정기가 아니다.
- `subtitle_forensics_v1`은 ABF-303 내부 그룹 교차검증 결과이며 다른 작품 일반화를 보장하지 않는다.
- 사진 연결은 사진 의미의 자동 판독이 아니다.
- `style-profiles`는 실제 화자 식별 결과가 아니다.
- 같은 Whisper 모델의 여러 패스는 독립 증거가 아니다.
- 다중 ASR은 직접 청취가 아니다.
- P1/P2 검토만으로 작품 전체 완료가 아니다.
- 미확정 세부사항을 자연스러운 창작으로 채우지 않는다.
- 이 통합 프로젝트는 원음·GPU·Whisper 모델이 없는 환경에서도 구조 검사와 검토 패킷까지는 동작하지만 ASR은 실행하지 않는다.
- 실제 일본어 청취 검증과 외부 골드 세트는 제공 자료에 없다.
