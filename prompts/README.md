# prompts

작품별 의미 판정 프롬프트는 공용 프롬프트를 자동 변경하지 않도록 별도 파일로 관리한다. 현재 제공된 기준 프롬프트는 `references/translation-prompt-v6.txt`이며, 작품별 프롬프트를 추가할 때는 작품 폴더나 명시적 경로로만 연결한다.

프롬프트는 원문에 없는 행동·신체 부위·위치·감정·관계·강압·결과를 추론해 추가하지 않으며, 확정 정보와 불확실 슬롯을 분리해야 한다.

## 사용 방법

Codex가 이 저장소에서 작업할 때는 루트의 `AGENTS.md`가 이 규칙과 번역 템플릿을 자동으로 라우팅한다. 사용자가 매번 긴 프롬프트를 붙여 넣을 필요는 없다.

작품 하나:

```text
프로젝트 규칙에 따라 ADN-622 번역을 시작해. 먼저 자료·근거·누락·충돌을 점검하고, 승인 없이 final을 만들지 마.
```

전체 작품:

```text
13개 작품을 프로젝트 규칙에 따라 순차 처리해. 자료 점검→근거 연결→GPT-5.6 의미 번역→검증 순서로 진행하고, 보류 사유와 결과 경로를 기록해.
```

실제 번역 결정은 `terra-semantic-translation-v1.md`, 전체 배치 작업은 `batch-adult-srt-translation-run.md`를 기준으로 한다.
